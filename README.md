# Proyek Kelompok Pengantar Algoritma Deep Learning (UTS)
**Topik:** Prediksi Harga Komoditas Pangan Menggunakan MLP Regresi (PIHPS Nasional)

## Struktur Repositori
- `data/` : Berisi file dataset Excel PIHPS (Beras & Cabai).
- `notebooks/` : Berisi file Google Colab `.ipynb` pelatihan model baseline.
- `models/` : Berisi file bobot model `.pth` hasil training.
- `reports/` : Berisi laporan kemajuan UTS dan gambar grafik evaluasi.

## Cara Menjalankan Program
1. Buka file notebook di folder `notebooks/` menggunakan Google Colab.
2. Hubungkan Google Drive yang berisi file dataset Excel PIHPS.
3. Jalankan sel (cell) secara berurutan dari atas ke bawah untuk mereplikasi hasil training dan kurva loss.
